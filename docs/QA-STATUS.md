# סטודיו — תיקוני זרימה וממשק צילום

3 בנובמבר 2026. הדוח המקורי וצילומי **לפני התיקון** נמצאים ב־[דוח הסריקה](qa/audit-2026-11-03.md).

## העיצוב

המצלמה/וידאו הם מרכז העבודה. האולפן והעורך חולקים במה אחת שמחשבת רוחב וגובה מאותו יחס תמונה, לפי המקום הפנוי לאחר הניווט. סרגל כלים צף וניתן לגלילה, כפתור הקלטה ממורכז, תפריט עליון מצומצם וחלוניות תחתונות מחליפים פריסה שנחתכת במובייל. שלבי ההפקה הם תסריט, צילום ועריכה.

הממדים מתעדכנים גם בשינוי גודל החלון ו־visual viewport. כלי צילום נעצרים כשהאולפן אינו פעיל, והעבודה נשארת בזיכרון ובשמירה המקומית. מעבר מסך בזמן הקלטה או ייצוא חסום כדי לא להפסיק אותם בטעות.

## סטטוס ממצאי הסריקה

| ממצא | טיפול |
|---|---|
| 01 — מקור מיובא גובר על הקלטה | מקור מדיה יחיד ב־App. בחירת מקור חדש יוצרת עורך חדש ללא שאריות. זרימת ייבוא → הקלטה מדומה → עורך נבדקה. |
| 02 — אובדן עבודה ברענון | שמירה אוטומטית ב־IndexedDB: Blob, תסריט, טייקים, כתוביות, חיתוך, מוזיקה, מדבקות ושכבות. שחזור נבדק בטעינת App מחדש. חיווי שמירה וכשל + אזהרת יציאה כשיש שינויים לא שמורים. |
| 03 — חלונית נסגרת בלחיצה בתוכה | החלוניות עוצרות bubbling. בדיקת הוספה והקלדה עוברת; Escape סוגר במפורש. |
| 04 — אובדן ספריית טייקים | רשימת טייקים בבעלות הפרויקט, עם שמירה ומגש לבחירה/מועדפים/מחיקה. |
| 05 — שתי גרסאות תסריט | תיבת ההדבקה והאולפן משתמשים באותו מקור אמת. נבדק עדכון מתוך האולפן וחזרה לתסריט. |
| 06 — קאבר לא מועבר | הטקסט מועבר לשדה הכותרת בעורך ונשמר; עריכה ידנית של הכותרת אינה נדרסת בשחזור. |
| 07 — לשוניות נחתכות | ניווט בן שלוש עמודות גמישות ותוויות קצרות; תג הסרטון הוחלף בחיווי קטן. אימות חזותי פיזי עוד נדרש. |
| 08 — עורך זולג למסכים אחרים | display:none מפורש, בלי התנגשות hidden/flex. נבדק ב־DOM. |
| 09 — בס/הדהוד לא מחוברים | גרף האודיו הקיים חובר להקלטה; שינויי gain ואפקטים מוחלקים. האזנה על חומרה עדיין נדרשת. |
| 10 — תאורה/זום בתצוגה בלבד | הקלטת המצלמה עוברת דרך canvas שמחיל אותו חיתוך, שיקוף, בהירות וזום דיגיטלי. נמנעת הכפלה של זום חומרה. צילום פיזי עוד נדרש. |
| 11 — שאריות עריכה ממקור קודם | החלפת זהות המדיה מאפסת את כל טיוטת העריכה. נבדק שכתובית אינה מועברת לייבוא חדש. |
| 12 — מיקס שונה בתצוגה ובייצוא | gain scale ו־bus משותפים לתצוגה ולשני מנועי הייצוא; הוסרו מכפילי 1.8 ו־1.5 הנסתרים. |
| 13 — גישה מטלפון | נוסף dev:network במפורש ותוקן תיעוד הפורט. שימוש במצלמה בטלפון עדיין דורש פריסת HTTPS תקפה; לא הוקמה פריסה חדשה. |
| 14 — יחס הבמה | רכיב CameraStage משותף מבצע fit לשטח הפנוי, לאחר padding. החישוב נבדק בכמה גדלים לרבות חלון קצר/מקלדת. גם חיתוך הייצוא תוקן כדי לא למתוח מקורות בעלי אותו כיוון אך יחס שונה. |
| 15 — עיוותים/תקתוקים | הוסרו הגברות נסתרות, נוסף limiter ומרווח שיאים במיקס, עיבוד PCM מוגבל לשיא 0.94 ו־fade של 5ms בקצוות. בלוק AAC האחרון מכיל רק את מספר הדגימות הנותר; אין flush באמצע רצועת האודיו. נתיב MediaRecorder מבודד מהנגן ועיבוד התצוגה. תקתוקים בהקלטה המקורית של המשתמש עדיין לא שוחזרו בהאזנה. |

בנוסף: חלונית השכבות חוברה לייבוא תמונות וטווחי זמן; השיתוף במובייל מופעל בכפתור נפרד אחרי הייצוא כדי לקבל מחוות משתמש חדשה. בדיקת חיבור Gemini אינה שומרת הגדרות לפני לחיצה על שמירה.

## אימות

- `npm test`: 11 בדיקות. כוללות תזמון כתוביות, יחס במה, חיתוך מדיה ללא מתיחה, שיאים/רציפות PCM, תזמון בלוקים ב־WebCodecs, שמירה ושחזור וזרימת App אמיתית ב־jsdom.
- בדיקת השמירה משתמשת ב־IndexedDB מדומה ושומרת Blob אמיתי. בדיקת ההקלטה מדמה את המכשיר וה־MediaRecorder ובודקת את callbacks של המוצר. בדיקת הייצוא משתמשת בכפילים ל־AudioEncoder/VideoEncoder; היא אינה מאמתת ביטסטרים AAC אמיתי או צלילות שמע.
- `npm run build`: בניית TypeScript ו־Vite עוברת.
- הגישה לדפדפן המקומי נחסמה בידי מדיניות הרשאה שמורה. לכן אין צילומי "אחרי" או אישור E2E בדפדפן לגרסה המתוקנת. צילומי הסריקה המצורפים הם של הגרסה הקודמת בלבד.

## בדיקות קבלה שנותרו

1. iPhone/Safari ו־Android/Chrome פיזיים דרך HTTPS: מצלמה, מיקרופון, מעבר קדמי/אחורי, מקלדת, מסך קצר, לרוחב ולאורך.
2. מקור דיבור מול ייצוא של אותה הקלטה בעייתית: peak/RMS והאזנה לתקתוקים; בנפרד WebCodecs ונתיב MediaRecorder.
3. ייצוא אמיתי של סרטון ארוך, כולל מוזיקה, חיתוך, כמה שכבות וסנכרון בתחילה/אמצע/סוף.
4. שיתוף/שמירה למכשיר אחרי הייצוא, ותרחישי אחסון מלא או הרשאות מדיה שנדחו.

בדיקת `npm audit` דיווחה על 3 advisories בתלויות פיתוח קיימות (Vite, source-map-js, postcss-selector-parser). לא בוצע שדרוג גורף במסגרת שינוי הממשק והאודיו.
