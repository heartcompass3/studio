# מצפן הלב | Studio Pro 🎬
מערכת סטודיו מקצועית להקלטת וידאו, טלפרומפטר חכם, עריכה, כתוביות ויראליות וייצוא MP4 המבוססת על שיטת מ.ס.ע.

## 🚀 איך מפעילים את הסטודיו?
1. לחץ לחיצה כפולה על הקובץ **`start_studio.bat`** (או הרץ `npm run dev` בטרמינל בתיקייה זו).
2. הדפדפן ייפתח אוטומטית בכתובת `http://localhost:3001`.
3. לחץ על סמל **גלגל השיניים (⚙️)** והזן את מפתח ה-**Gemini API Key** שלך (נשמר ב-LocalStorage המקומי).

---

## 💎 היכולות המרכזיות במערכת:
1. **סקריפטים ו-Hooks (Script Engine Pro):**
   - 8 ארכיטיפים פסיכולוגיים מובנים לפי שיטת מ.ס.ע.
   - מחולל 3 וויז'ואלים ו-Hooks ויראליים בלחיצה אחת.
   - הערכת זמני קריאה משוערים וכמות מילים (135 מילים לדקה בעברית).
   - כפתור ישיר: "שלח לאולפן".

2. **אולפן הקלטות Broadcast:**
   - איכות HD עם יחסי תצוגה 9:16 (רילס/טיקטוק) ו-16:9 (יוטיוב).
   - מד ווליום חי (Audio VU Meter) עם התראה על צרימות (Clipping).
   - ספירה לאחור (3-2-1) לפני תחילת הקלטה.
   - טלפרומפטר בגלילה חלקה עם קו מרכז מבט (Eye Contact Target).
   - רינג לייט ותאורת סטודיו מתכווננת.

3. **עורך וידאו וכתוביות MP4:**
   - ציר זמן ויזואלי לחיתוך (Trim Start / End) במילי-שניות.
   - תמלול אוטומטי בעברית ע"י Gemini.
   - סגנונות כתוביות ויראליות: צהוב זוהר (Hormozi), ירוק (Beast), שחור מודגש ולבן.
   - עורך כתוביות מלא וייצוא קובצי `.SRT`.
   - **ייצוא אמיתי ל-MP4 (H.264/AAC)** ברינדור פריים-אחר-פריים לא מקוון.

4. **מעבדת הצעת הזהב (Hormozi):**
   - פיצוח משוואת הערך, הכאב הקריטי (Bleeding Neck), תוצאת החלום ופיץ' מנצח.

5. **כלי מ.ס.ע נוספים:**
   - מחולל הודעות WhatsApp לחיבור מחדש לאחר פיצוץ (3 סגנונות).
   - מתורגמן סערת המתבגר לשפה רגשית פנימית.
   - מיפוי 6 מרכיבי הלופ המשפחתי וזיהוי "החלק השומר".
   - חדר טיפולים & סימולטור מתבגר בזמן אמת.


## סביבת צילום מרכזית ושמירה מקומית
- הפריים באולפן ובעורך שומר על יחס התמונה בתוך השטח שנותר לאחר הניווט. הכלים צפים מעליו; ההגדרות נפתחות בחלונית תחתונה.
- התסריט, הסרטון, כל הטייקים והעריכה נשמרים אוטומטית ב־IndexedDB באותו דפדפן ובאותה כתובת. חכה לחיווי **נשמר במכשיר** לפני סגירה. זו אינה שמירה בענן או גיבוי בין מכשירים.
- מקור וידאו חדש פותח עריכה חדשה; הוא אינו יורש כתוביות וחיתוכים מהסרטון הקודם.
- השמע נשמר ללא הגברה נסתרת; המיקס כולל מרווח לשיאים, הגבלת שיאים והחלקת קצוות חיתוך.

### בדיקה בטלפון
להצגת הממשק ברשת מקומית אפשר להפעיל במפורש `npm run dev:network` ולפתוח בטלפון את כתובת המחשב בפורט 3001. לצילום עם מצלמה ומיקרופון בטלפון יש להשתמש בכתובת HTTPS עם תעודה תקפה. חיבור HTTP לכתובת הרשת מיועד לבדיקת הממשק בלבד; שרת הפיתוח אינו פריסת מוצר.

### בדיקות
`npm test` מריץ בדיקות כתוביות, יחס תמונה, עיבוד PCM, שמירה ושחזור ומעברי מסכים. בדיקות DOM משתמשות ב־jsdom וב־IndexedDB מדומה; הן אינן תחליף לבדיקת צילום, קודקים ושמע על iPhone ו־Android.

### מיקום וגודל כתוביות וטקסטים
נגיעה בפריים בעורך עוצרת או ממשיכה את הניגון. אפשר לגרור כתובית, כותרת או מדבקת טקסט ישירות על הסרטון, באצבע או בעכבר; תחילת הגרירה עוצרת את הניגון. בחלוניות **כתוביות**, **סגנון** ו־**מדבקות**, הכפתור **מקם בגרירה על הסרטון** סוגר את החלונית ובוחר את הטקסט למיקום. כתוביות ומדבקות מוצגות בנקודת הזמן שלהן. לאחר הבחירה אפשר להזיז גם בחיצי המקלדת (Shift לתזוזה גדולה יותר).

בחלוניות נשארו שינוי גודל הטקסט (50%–200%) ואיפוס. שדות הטקסט בעברית מיושרים לימין וכיוון ההקלדה מימין לשמאל. המיקום והגודל נשמרים בפרויקט ומוחלים גם בקובץ המיוצא. בדיקת פענוח התוצר מתבצעת לפני ההורדה; בזמן הייצוא יש להשאיר את הדף פתוח.
